## 해석과 미검증

- ValueResolver가 지원하는 구문·이름 기반 후보를 연결하며 reaching definition/alias/실행 가능성 해석을 추가하지 않았다.
- 미지원 배열/복합 포인터, 매크로, ARXML/wiring, Runnable 순서, 조기 반환/loop/switch 조건 등은 미해결·불확실성으로 남는다.
- 전역 입력 후보는 외부 연결 이름 기반이다. static/const 제외가 실제 CT 접근 가능성을 증명하지 않는다.
- 노드/깊이/시간/지점당 출처64개/연결 한도가 있으며 중단은 일부 탐색으로 표시한다.
  탐색 시간 예산은 해석 단계 사이에서 확인하므로 단일 해석 작업은 넘길 수 있다. 전체 프로세스 제한 시간과 응답8MiB 제한도 적용된다.
- 그래프 순환은 후보 관계의 반복이며 실제 프로그램 무한 반복 증명이 아니다.
- 미리보기 결과 전체·모든 선택 경로의 일괄 저장은 하지 않는다. 명시적 지점 추가만 기존 이력에 저장한다.
- 실제 고객 대형 코드·CT 제어/실행·장기 누수·다른 PC/OS·수동 화면 육안 검증은 하지 않았다.
  Host는 실제 VS Code API 자동 검증이며 사용자가 UI를 직접 써 본 결과와 구분한다.


### 2026-11-15 후속 해석 정정
