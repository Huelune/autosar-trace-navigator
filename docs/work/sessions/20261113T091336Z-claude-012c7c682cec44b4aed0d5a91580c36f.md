## 미검증·문제·결정

- 체크 목록 화면을 사람이 직접 조작해 보지 않았다. 실제 업무에서 붙여넣는 글의 모양으로 분류가 맞는지도 보지 않았다.
- 결정: 미리보기는 VS Code의 여러 개 고르기 목록을 썼다. 별도 화면을 만들지 않았다.
- 결정: 만든 단계는 형제로 두고 현재 단계를 바꾸지 않는다. 붙여넣은 목록은 한 경로가 아니라 조사할 후보들이기 때문이다.
- 한계: 이름표는 글자 모양만 본다. 예를 들어 비교 연산자가 든 한 줄은 세미콜론이 없으면 조건식으로 본다. 틀린 이름표는 저장 뒤 이유를 고쳐야 한다.
- 한계: 경로 항목도 파일에 연결되지 않는다. 함수명·경로 목록 중간에 다른 모양의 줄이 섞이면 묶음 전체가 코드 한 덩어리가 된다.
- Python 쪽은 바꾸지 않아 다시 돌리지 않았다.
