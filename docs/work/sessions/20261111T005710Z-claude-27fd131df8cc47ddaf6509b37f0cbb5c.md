## 미검증·문제·결정

- **자동 보안 검토가 찾은 문제**: 첫 커밋(`e555d3b`)은 `declaration:` 형태만 상대 경로로 바꿨는데, 구조체 분석이
  `initializer_declaration: <절대 경로>:<줄>` 형태도 만든다. 그대로면 응답과 저장된 관계에 절대 경로(계정 이름 포함 가능)가
  남을 수 있었다. `3dc85a0`에서 고쳤고 테스트로 확인했다. `e555d3b`만 따로 가져가 쓰지 않는다.
- Host 테스트의 목록 선택·이유 입력은 테스트 포트로 응답했다. 사람이 직접 조작한 확인은 없다.
- 값 출처 후보가 많은 함수에서 목록이 얼마나 길어지는지, 실제 프로젝트에서의 유용성은 확인하지 못했다.
- 한 조건에 변수가 여러 개여도 조건 하나를 후보 하나로 낸다(Tkinter 쪽은 변수마다 후보). 변수별 출처는 그 변수에 커서를 두고 다시 조회한다.
- 조회마다 범위를 새로 파싱하는 것은 그대로다. 값 분석이 더해진 뒤의 소요 시간은 재지 않았다.
- 사내 PC의 Python 실행 허용, 비UTF-8 파일 빈도는 TASK-002와 같이 미확인이다.
