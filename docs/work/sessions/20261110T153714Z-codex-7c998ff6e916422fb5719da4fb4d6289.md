## 미검증·문제·결정

- 최초 격리 실행의 npm 캐시는 불완전해 ENOTCACHED로 실패. 준비된 개발 캐시를 사용한 오프라인 재실행은 성공.
- 최초 기록 테스트와 uv editable 빌드는 격리 TEMP의 WinError 5로 실패. 저장소 build/worklog-temp를
  현재 셸 TEMP/TMP로 지정한 뒤 테스트/설치 성공. uv는 hardlink 대신 `--link-mode copy` 사용.
- 실제 회사 Claude Code의 지침 로딩·회사 정책/권한·다른 PC·다른 OS는 미검증.
  Claude import는 공식 문서를 확인해 구성했으며 설치된 회사 버전에서 확인해야 함.
- 이번에는 Host/native UI를 재실행하지 않음. 변경은 개발 준비/협업 기록에 한정되고 확장 런타임은 미변경.
- Git 카드 담당은 분산 잠금이 아니다. 공유 전 한 담당/범위를 정하고 세션 파일은 개별 보존.
- 고객/회사 소스·CT 자료·개인 AI 메모리는 반입하지 않음. 사용자 미추적 지시서는 그대로 보존.
