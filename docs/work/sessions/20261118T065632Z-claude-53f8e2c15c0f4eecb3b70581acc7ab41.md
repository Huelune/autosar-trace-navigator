## 미검증·문제·결정

- 실제 VS Code 웹뷰 안에서 사람이 조작해 보지 않았다. Host 테스트는 웹뷰 DOM에 접근할 수 없어 스크립트 동작은 브라우저 렌더로만 확인했다.
- 고대비 테마는 CSS(contrastBorder)로만 확인했다. 행 번호 대비(3.08:1)는 편집기 행 번호 색을 그대로 쓴 것이다.
- 결정: 다른 단계의 초안은 안내만 하고 이동 버튼은 두지 않았다. 화면 메시지 종류를 늘리지 않기 위해서다.
- 결정: 저장 성공은 다시 그린 화면 값이 초안과 같은지로 판단한다. 같은 값으로 다른 곳에서 바뀐 경우에도 "저장됨"이 뜰 수 있다.
