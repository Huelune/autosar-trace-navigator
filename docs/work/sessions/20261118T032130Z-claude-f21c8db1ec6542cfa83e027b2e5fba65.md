## 미검증·문제·결정

- 점검 화면을 사람이 직접 조작해 보지 않았다. 측정은 이 PC에서 한 번씩이며 작은 파일로만 이뤄진 가상 프로젝트다. 실제 작업 폴더의 시간은 다를 수 있다.
- 취소는 기존 프로세스 중단 경로(어댑터 단위 테스트가 다룸)를 그대로 쓴다. 점검 요청으로 따로 시험하지 않았다.
- 결정: 점검을 분석 앞에 자동으로 끼우지 않았다. 매 조회마다 시간이 더 들고, 한도 초과는 이미 원인과 함께 알려 주기 때문이다.
- 결정: 폴더는 경로 앞 두 마디로 묶는다. 깊은 구조에서는 묶음이 너무 클 수 있다.
- 한계: 크기는 점검 시점의 파일 시스템 값이다. 분석 시간과 메모리는 예측하지 않는다.
