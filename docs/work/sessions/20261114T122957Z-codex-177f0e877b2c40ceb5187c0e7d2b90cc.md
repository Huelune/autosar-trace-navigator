## 최종 인계

사용법: 선택 변수/멤버 우클릭 → 변수 전체 출처 미리보기. 이 코드 조사에 추가를 누르고 이유를 입력해야 한 단계가 저장된다.

미리보기는 지원 후보 전체 연결이다. 실제 가능한 모든 실행 경로, 목표값 해, CT 입력 가능성/wiring/실행 순서 확정과 구분한다.
수동 육안 UI 검증·회사 소스·다른 OS·CT·장기 성능은 미검증이다. 전체 선택 경로 일괄 저장은 포함하지 않았다.
