## 실패 시도와 정정

- 수정 전 Zig 0.15.2는 macOS SDK 시스템 심볼을 링크하지 못했다. 시스템 Clang 우선 선택으로 해결했다.
- 수정 전 전체 테스트는 앞선 GUI 클래스 이후 `Tk.update()`에서 멈췄다. 스레드 덤프에서 분석 작업자는 이미 유휴 상태였고
  주 스레드만 Tk 이벤트 처리 안에서 대기함을 확인해 비차단 단일 이벤트 처리로 수정했다.
- Tk 객체 정리만 추가한 첫 시도는 멈춤을 해결하지 못했다. 정리 기준 통일은 유지하되 실제 해결책과 구분했다.
