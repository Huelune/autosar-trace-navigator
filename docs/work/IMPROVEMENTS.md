# 후속 개선 후보 (구현 승인 전)

이번 통합의 범위는 한도·제외 경로와 긴 조사 표시다. 아래는 사용자에게 제안하는 후속 후보이며,
카드 작성 또는 목록 등록만으로 착수하지 않는다.

| 순서 | 개선 | 기대 효과 | 먼저 검증할 것 |
|---|---|---|---|
| 1 | 분석 전 범위 점검: C/H 개수·크기, 제외 폴더, 예상 한도 초과 표시 | 기다린 뒤 실패하는 일을 줄이고 범위를 고르기 쉽게 함 | 가상 대형 프로젝트에서 스캔 시간과 취소, 원본 무변경 |
| 2 | 파일 인덱스·변경분 파싱 또는 분석 스냅샷 재사용 | 다른 변수·함수를 처음 조회할 때 반복 전체 파싱 줄임 | 현재 첫 조회/반복 조회 시간·메모리를 먼저 측정하고 변경·제외·인코딩별 무효화 설계 |
| 3 | CT 입력·필요 조건 요약 | extern 가능한 전역 입력 후보와 중간 계산·선행 조건을 한곳에서 검토 | static/const 제외, RTE 연결·실행 순서 미확정, 조건 충족을 증명으로 표시하지 않음 |
| 4 | 미해결 조사와 다음 행동 목록 | 30~40단계 중 돌아갈 지점과 보류 이유를 찾기 쉽게 함 | 기존 상태·검색·nextAction을 재사용하며 별도 중복 기록 방지 |

별도 브랜치 `feat/TASK-019-export`의 export는 기존 구현을 검토할 후보다. 이번 통합에 포함하지 않는다.
SQLite import는 기존 사용자 결정대로 후순위다. CT 자동 조작과 고객 자료 반입은 포함하지 않는다.
