## 목적과 승인 범위

[후속 개선 후보](../IMPROVEMENTS.md) 4번. 사용자가 "미해결 조사와 다음 행동 목록 시작"으로 승인했다.
30~40단계 조사에서 돌아갈 지점과 보류 이유를 찾기 쉽게 한다.

- 미해결 단계를 한 목록으로 보여 주는 명령을 추가한다.
- 미해결의 기준: 보류한 단계, 조사 중이면서 다음 할 일이 적힌 단계, 조사 중인 채 끝난 갈래의 마지막 단계.
- 기존 상태·다음 할 일 기록에서 읽기만 한다. 별도 목록을 저장하지 않는다.
- 고른 단계는 방문만 한다.

## 범위 밖

- 목록에서 바로 상태를 바꾸거나 다음 할 일을 고치는 것. 상세 창에서 한다.
- 기한·우선순위·담당자 같은 새 항목. 저장 형식을 바꾸지 않는다.
- 트리에 미해결 표시를 따로 붙이는 것.
- 후속 개선 후보의 다른 항목(범위 점검, 분석 재사용 확대, CT 입력 요약).
