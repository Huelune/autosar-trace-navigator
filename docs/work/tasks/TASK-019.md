## 목적과 승인 범위

사용자 요청: 조사 기록을 내보내고 싶다. 전달용과 시각화용으로 여러 방식이면 좋겠다.

- 목표 하나를 파일로 내보내는 명령을 추가한다.
- 전달용: Markdown 문서. 코드 포함과 코드 제외 두 가지.
- 시각화용: 브라우저로 여는 HTML 트리 그림과 Mermaid 흐름도 글.
- 사용자가 형식과 저장 위치를 고른다. 조사 기록은 바꾸지 않는다.

형식 네 가지와 내용 구성은 사용자가 세부를 정하지 않아 담당자가 정했다. 써 본 뒤 바꿀 수 있다.

## 범위 밖

- 여러 목표를 한 파일로 내보내기, 일부 갈래만 내보내기.
- 내보낸 파일을 다시 읽어 들이기(import). 다른 PC로 기록 자체를 옮기는 것은 저장 파일 복사로 한다.
- PDF·이미지 파일 직접 생성. HTML을 브라우저에서 인쇄한다.
- 파일 경로를 가리거나 바꾸는 것. 작업 폴더 기준 경로는 그대로 들어간다.
- 네트워크 전송. 확장은 고른 위치에 쓰기만 한다.

- [x] 설치용 VSIX 재빌드, README·CHANGELOG·STATUS·세션 기록 갱신
