## 목적과 승인 범위

원본 지시서 11절 P1의 "함수명/경로/조건식/여러 줄 코드/경로 목록 일괄 붙여넣기 → 분류·분할 미리보기 → 사용자 확인 후 단계화"를 구현한다.
사용자가 "일괄 붙여넣기 분류 시작"으로 승인했다.

- 붙여넣은 글을 빈 줄로 나누고, 함수명·경로만 있는 묶음은 줄마다 나눈다.
- 항목마다 함수명·경로·조건식·코드 중 하나의 이름표를 붙인다.
- 나눈 결과를 모두 체크된 목록으로 보여 주고, 사용자가 확인한 항목만 단계로 만든다.
- 만든 단계는 현재 단계 아래의 형제이며 한 번에 저장한다. 현재 단계는 바꾸지 않는다.

## 범위 밖

- 경로나 함수명을 실제 파일 위치에 연결하는 것. 모든 항목은 파일 미연결 스니펫 단계다. 연결은 기존 위치 재연결로 한다.
- 미리보기에서 이름표나 내용을 고치는 것, 항목을 합치거나 다시 나누는 것. 이유는 저장 뒤 상세 창에서 고친다.
- Python 엔진으로 분류를 확인하는 것. 이름표는 글자 모양만 본다.
- 항목마다 이유를 따로 묻는 것. 이유는 `이름표: 내용 한 줄`로 채운다.
