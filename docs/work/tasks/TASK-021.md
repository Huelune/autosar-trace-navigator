## 목적과 승인 범위

[후속 개선 후보](../IMPROVEMENTS.md) 1번. 사용자가 "분석 전 범위 점검 시작"으로 승인했다.
분석을 기다린 뒤 한도 초과로 실패하는 일을 줄이고, 범위와 제외 경로를 고르기 쉽게 한다.

- 지금 설정이 고르는 C/H 파일 수, 소스 합계, 가장 큰 파일을 한도와 비교해 보여 주는 명령을 확장에 추가한다.
- 파일이 많은 폴더를 크기순으로 보여 준다.
- Python 브리지에 범위 점검 요청을 추가한다. 파일 내용은 읽거나 파싱하지 않는다.
- 분석과 같은 범위·제외 경로·한도 설정을 따른다.

## 범위 밖

- 점검 화면에서 바로 제외 경로나 한도를 바꾸는 것. 설정 화면을 여는 항목만 둔다.
- 분석 시간 예측. 한도 안이어도 제한 시간을 넘길 수 있다.
- 관련 후보 조회나 함수 검색 앞에 점검을 자동으로 끼워 넣는 것. 사용자가 명령으로 실행한다.
- 후속 개선 후보의 다른 항목(분석 재사용 확대, CT 입력 요약).
