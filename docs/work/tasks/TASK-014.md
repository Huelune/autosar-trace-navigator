## 목적과 승인 범위

써 본 사람의 피드백 두 건을 고친다. 사용자가 원인 보고를 본 뒤 "수정 진행"으로 승인했다.

## 범위 밖

- 검색 탭에 있을 때 새 단계가 저장됐음을 따로 알리는 표시. 상태 표시줄 안내는 그대로다.
- 조사 단계 검색 명령으로 단계를 골랐을 때 조사 탭을 여는 동작. 찾은 단계를 보여 주는 것이 목적이라 그대로 뒀다.
- 저장 형식, Python 엔진.
