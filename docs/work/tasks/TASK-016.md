## 목적과 승인 범위

남은 P1 가운데 함수 검색과 결과 캐시를 구현한다. 사용자가 "후자부터 하자"로 승인했고, SQLite import는 도구의 실사용이 아직 없어 뒤로 미뤘다.

- 분석 범위의 함수 정의를 이름·경로로 찾아 그 선언으로 이동하는 명령을 확장에 추가한다.
- Python 브리지에 함수 목록 요청을 추가한다. 기존 관련 후보 요청은 그대로 둔다.
- 함수 목록과 관련 후보 조회 결과를 작업 폴더의 C/H 파일이 바뀔 때까지 다시 쓴다.

## 범위 밖

- 찾은 함수를 바로 단계로 만드는 것. 고르면 이동해 선언을 선택하기만 한다.
- 디스크에 남는 캐시, 오래 떠 있는 엔진 프로세스. 캐시는 창이 열려 있는 동안의 메모리에만 있다.
- 작업 폴더 밖 파일의 변경 감지. 분석 범위가 그런 파일을 가리키면 창을 다시 불러와야 한다.
- 선언(prototype)·매크로·호출 위치 검색. 엔진이 파싱한 함수 정의만 나온다.
- SQLite 읽기 전용 import.
