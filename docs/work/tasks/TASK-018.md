## 목적과 승인 범위

사용자 피드백: 조사 중간에 새 루트를 시작하면 트리에서 잘 보이지 않는다.
원인과 개선안을 보고한 뒤 사용자가 "그렇게 진행"으로 승인했다.

- 갈림길 아래에는 각 갈래의 첫 단계만 나란히 놓고, 그 갈래의 나머지 단계는 첫 단계 아래에 묶는다.
- 갈래의 첫 단계에 단계 수와, 현재 단계가 그 갈래 안에 있는지를 표시한다.
- 화면 배치만 바꾼다. 저장 형식과 단계 관계는 그대로 둔다.

## 범위 밖

- 새 루트를 시작하는 조작(상위로 이동한 뒤 추가)을 바꾸는 것.
- 갈래에 이름을 붙이거나 색을 다르게 하는 것, 갈래 순서 바꾸기.
- 접은 상태를 저장하는 것. 접기·펴기는 VS Code 트리의 기본 동작에 맡긴다.

## 완료 조건

- [x] 갈림길은 갈래의 첫 단계만, 첫 단계는 자기 갈래의 나머지 단계를 자식으로 보여 줌
- [x] 모든 단계가 한 번씩만 나오고, 트리에서 드러내기에 쓰는 부모가 표시 위치와 일치
- [x] 갈래 첫 단계의 단계 수·진행 중 표시
- [x] 단위 테스트와 Host 확인 통과, 설치용 VSIX 재빌드, README·CHANGELOG·STATUS·세션 기록 갱신
