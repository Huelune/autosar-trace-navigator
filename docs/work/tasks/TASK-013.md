## 목적과 승인 범위

원본 지시서 11절 P1의 "목표·조건·이유 검색과 상태 필터"를 구현한다. 사용자가 "검색 필터 시작"으로 승인했다.

- 모든 목표의 단계를 한 목록으로 보여 주고 입력한 글자로 거르는 검색 명령을 추가한다.

- 상태 필터는 같은 목록에서 상태 이름을 입력해 거르는 방식으로 제공한다.
- 고른 단계는 방문만 한다. 새 단계·관계를 만들지 않는다.

- 저장 형식 변경, Python 엔진의 함수 검색.
