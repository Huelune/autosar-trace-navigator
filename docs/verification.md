# 현재 범위 검증 결과

2026-11-06, Windows x64 / Python 3.14.3 / Zig 0.15.2 C 컴파일러 환경에서 검증했다.

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
.venv\Scripts\python -m pip check
git diff --check
```

| 검증 | 결과 |

| 환경 테스트 | 4개 통과 |

| 스캐너 단위 테스트 | 11개 통과 |

통합 검증은 정상 C/H 11개와 파서 전용 3개를 함께 검색·분석한다. 파서 전용
malformed.c에서만 구문 오류가 기록되고 정상 파일의 결과는 보존된다.
함수/분기 ID의 중복 여부, 소속 함수·부모 분기·체인 참조, 바이트 범위,
반복 분석 결과의 동일성 및 별도 번역 단위의 동명 함수 구분을 확인한다.

AUTOSAR 샘플의 목표 else-if 10행, 6단계 호출 후보 경로와 미확장 매크로 표시는
제품 파서 API로 검증했다. 원본 파일의 내용 해시와 수정 시각 불변 검증도 통과했다.

Trace Manager는 6단계 조사 중 목표 유지, 조사 이유 보존, 뒤로 이동 후 대안 경로
보존, 잘못된 이동 거부를 검증했다. SQLite는 임시 DB에서 재개 시 커서·대안 경로·
불확실성 복원, 동시 갱신 충돌, 손상 데이터 및 타 DB 거부, 저장 실패 롤백과
다른 세션 보존을 검증했다. 실제 사용자 DB는 수정하지 않았다.

RTE 단위 검증은 전체 접미사 구분, 중복 헤더, 미확장 매크로, 조건부 다중 공급자,
누락·미지원 API를 다룬다. 샘플에서 접근 7개, 데이터 연결 후보 2개를 추출했고
Speed_Raw·Pedal_Percent의 공급자 후보가 SensorAcquisition_10ms임을 확인했다.
6단계 호출 조사 뒤 공급자 후보로 이동한 8개 단계의 경로를 저장·복원하여 목표와
이름 기반 연결이라는 불확실성이 보존됨을 확인했다. 원본 해시·수정 시각도 동일했다.

이번 결과는 구문·이름 기반 RTE 후보 분석과 가상 실행의 검증이다. 실제 C 심볼 연결,
ARXML 배포 연결·실행 순서 해석, ECU 실행, 전체 분기 커버리지 측정을 포함하지 않는다. Python 3.11~3.13 및
다른 OS는 이번 실행에서 검증하지 않았다. 링크 제외 테스트는 Windows 링크 생성
권한에 의존하지 않도록 분류를 모의 처리한다.

초기 환경 준비 때 로컬 wheel만 이용한 `--no-index` 재설치도 검증했다.
현재 스캐너·파서는 네트워크 접근이나 전처리기 실행을 요구하지 않는다.
